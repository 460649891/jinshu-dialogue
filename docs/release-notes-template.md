# Release 说明模板

使用时复制下方内容到本地发布说明文件，替换全部占位符，并删除不适用项目。不直接将本模板发布为 Release。

```markdown
## 金书对话录 vX.Y.Z

一句话说明此次版本解决的问题或带来的行为。

### 下载与使用

- Windows x64：下载 JinshuDialogue-X.Y.Z-windows-x64.zip，完整解压后运行 JinshuDialogue.exe。
- 源码：下载 JinshuDialogue-X.Y.Z-source.zip；完整提交也保留在本版本标签。
- SHA256SUMS：用于检查两个发行 ZIP。

### 变化

- 具体的新增、修复与变化，避免重复列出没有变化的功能。

### 验证与范围

- 自动测试：填写本版本实际结果。
- 独立解压：填写真实验证的平台与结果。
- 游戏实测：填写版本、场景与限制，区分模拟测试。

### 已知限制

- 写清仍存在且会影响用户使用的边界。
```
